# Digital Voting Machine with Secure Memory

## Project Description

This project implements a digital voting machine using Verilog HDL.

## Features

- State machine based voting control
- Vote counting for three candidates
- Switch debouncing
- EEPROM/Flash memory model
- Data integrity verification using checksum
- 7-segment display
- Verilog simulation and waveform analysis

## Candidates

- Candidate A
- Candidate B
- Candidate C

## Simulation Results

Candidate A: 1 vote
Candidate B: 2 votes
Candidate C: 1 vote

Memory Integrity: Valid

## Tools Used

- Verilog HDL
- EcrioniX Verilog Simulator
- Icarus Verilog
- VCD Waveform Viewer
